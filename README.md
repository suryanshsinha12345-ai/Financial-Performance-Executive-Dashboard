# Financial Performance Executive Dashboard

## 📌 Overview

An interactive Power BI executive dashboard designed to provide a consolidated view of financial performance across revenue, profitability, cash flow, budget variance, products/services, and regions.

The dashboard enables users to explore financial performance using interactive filters and KPI-driven visualizations.

---

## 📊 Key KPIs

- **Total Revenue:** 24M
- **Gross Margin:** 45.5%
- **Net Cash:** 688K
- **EBITDA:** 24.8%

---

## 🎛️ Interactive Filters

The dashboard includes filters for:

- Month
- Year
- Quarter
- Region
- Product/Service

---

## 📈 Dashboard Analysis

The dashboard provides visual analysis of:

- Revenue & Gross Profit Trends
- Revenue vs Revenue Budget by Month
- Revenue by Product/Service
- Average Receivables Aging by Region
- Cash Flow by Component
- Budget Variance % by Month
- Total Revenue by Region
